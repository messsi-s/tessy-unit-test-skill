# 覆盖度复核清单（独立 reviewer 用）

输入：被测源码、TESSY details XML（interfaceReport + 用例列表）、覆盖率报告（如有）。

## 1. 分支基准

- [ ] 列出被测函数**全部判定表达式**（`if/else if/while/for/switch/?:/&&/||`）；
- [ ] 对每个判定列出分支数（`if` 2 条；`switch` case 数 + default；`&&`/`||` 每个子条件单独计 MC/DC）；
- [ ] 标记：有赋值的分支 / 空分支（只有 `;`）/ 不可达分支（物理上到不了，需给理由）。

## 2. 用例对照

- [ ] 每条分支是否至少有一条用例命中？
- [ ] 边界值：`<` 与 `<=` 的边界两侧是否都有用例？
- [ ] 越界值（低于下限 / 高于上限）是否覆盖？
- [ ] `default` / `else` 分支是否覆盖？
- [ ] 空分支是否被单独执行到（覆盖率需要，断言可为 `*none*`）？
- [ ] `||`/`&&` 的每个子条件是否都出现过真/假（MC/DC）？缺哪个？

## 3. 桩与输入可控性

- [ ] 每个外部依赖函数的桩类型（advanced/normal/none）是否与数据写法一致？
- [ ] 需要用桩返回值控制的分支，测试数据里是否真的给了值（高级桩变量 / 普通桩桩体）？
- [ ] 高级桩参数期望值是否齐全（缺了会 notok）？
- [ ] 内部调用（本地函数）是否已建高级桩，能否注入返回值？
- [ ] 函数 static 变量是否作为输入显式给出（独立执行时）？

## 4. 覆盖率口径

- [ ] 是否开启仪器化（`TESTOBJECT_ONLY`/`CALLED_FUNCTIONS`）？
- [ ] C0/C1 数字是否来自**真实执行**（不是 NONE 模式下的空值）？
- [ ] 未覆盖语句/分支逐条列出，并给出原因分类：
  - 桩不可控 / 输入缺失 / 用例不足 / 物理不可达 / 结构体返回无接口；

## 5. 输出格式（review/coverage_review.md）

```markdown
# 覆盖度复核

## 结论
- 分支总数：N；已覆盖：M（xx%）
- 判定：通过 / 需补用例

## 逐函数
| 函数 | 分支数 | 已覆盖 | 未覆盖分支 | 原因 | 需补用例 |
|---|---|---|---|---|---|
| appl_xxx | 10 | 9 | alpha=63 保持区间 | 桩不可控 | 补 TC03 |

## 不可达分支说明（如有）
- 分支：...；原因：...；依据：...（源码行号/硬件依赖）

## 建议补充用例（给到可执行粒度）
1. 用例名 / 输入 / 期望 / 覆盖分支
```
